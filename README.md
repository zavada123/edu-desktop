# edu-desktop — тренажер «Робочий стіл»

Навчальний тренажер для уроків інформатики в 3–9 класах. Учень працює з папками й файлами на робочому столі, схожому на Windows, просто в браузері: на комп'ютері, планшеті й телефоні. Тренажер сам перевіряє, чи виконано завдання, і підказує, що не так.

**Демо:** https://zavada123.github.io/edu-desktop/

## Що вміє

- Робочий стіл, вікна провідника, панель задач, кошик, «Цей ПК» з дисками C: і D:.
- Адресний рядок як у Windows: клацання на порожнє місце показує повний шлях `D:\Мої уроки\Інформатика`, шлях можна ввести й натиснути Enter.
- Меню «Створити → Папку / Текстовий документ», перейменувати, копіювати, вирізати, вставити, видалити, відновити з кошика, видалити назавжди, очистити кошик.
- Вікно «Перемістити у кошик?» перед видаленням.
- Ярлики: «Створити ярлик» і «Надіслати → Робочий стіл (створити ярлик)», значок зі стрілкою; ярлик відкриває свій об'єкт, а його видалення об'єкт не чіпає.
- Перетягування правою кнопкою миші: меню «Копіювати сюди / Перемістити сюди / Створити ярлики». Повільне друге клацання по назві виділеного об'єкта — перейменування.
- Програми з вікнами «Зберегти як» і «Відкрити»: Paint (можна малювати), текстовий редактор, браузер із «Зберегти зображення як…». Завдання вмикає програму полем `app: { kind: "paint" }`.
- Стиснуті ZIP-папки: «Надіслати → Стиснута ZIP-папка», архів відкривається як папка, «Видобути все…». Shift+клацання виділяє діапазон.
- Кнопки вікна «Згорнути», «Розгорнути», «Закрити»; згорнуте вікно повертається кнопкою на панелі задач.
- Виділення кількох об'єктів: Ctrl+клацання, на телефоні — кнопка «Вибрати кілька».
- Перетягування на папку або в кошик (Ctrl — копіювати).
- Гарячі клавіші, як у Windows: Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+A, Delete, F2, Enter, Backspace, Escape. Працюють і на українській розкладці.
- Меню правою кнопкою миші; на телефоні — довге натискання. Подвійне натискання відкриває.
- Правила назв як у Windows: заборонені символи, імена пристроїв (NUL, PRN, CON…), «Нова папка (2)», «море – копія.jpg».
- Великий режим для 3–4 класу.
- Усе українською.

## Як описати завдання

Завдання — це об'єкт `Scenario` (`src/scenarios`): що лежить на робочому столі на початку і які умови перевірити наприкінці. Програмувати не треба.

```ts
const animals: Scenario = {
  id: "g3-folder-animals",
  grade: 3,
  title: "Папка для тварин",
  large: true,
  task: ["Створи на робочому столі папку «Тварини».", "Перенеси в неї малюнки кота і собаки."],
  // Об'єкт — папка, null — файл, рядок — ярлик до цього шляху ("Ігри – ярлик": "D:/Ігри").
  // Папка з назвою на .zip — стиснута ZIP-папка.
  start: { "кіт.png": null, "собака.png": null, Документи: {} },
  // Необов'язково: вміст дисків у «Цей ПК». Умови звертаються до них як "D:/Мої уроки/...".
  drives: { "D:": { "Мої уроки": {} } },
  goals: [
    { type: "exists", path: "Тварини", kind: "folder" },
    { type: "exists", path: "Тварини/кіт.png", kind: "file" },
    { type: "count", folder: "Тварини", ext: "png", equals: 2 }
  ]
}
```

Умови (`Goal`):

| Тип | Що перевіряє |
|---|---|
| `exists` | За шляхом є папка, файл або ZIP-папка (`kind: "zip"`) |
| `absent` | За шляхом нічого немає |
| `inBin` | Об'єкт із такою назвою лежить у кошику |
| `shortcut` | У папці є ярлик (з будь-якою назвою), що відкриває вказаний об'єкт |
| `opened` | Файл за шляхом відкрили в програмі через «Файл → Відкрити» |
| `restored` | Об'єкт за шляхом видаляли в кошик і відновили |
| `count` | У папці рівно N об'єктів (можна лише папок, лише файлів або файлів з певним розширенням) |

Кожній умові можна дати свій текст (`text`) і підказку на випадок помилки (`hint`).

## Як вбудувати

Пакет має дві частини. `edu-desktop/core` — ядро без React: файлова система, умови, журнал дій і всі сценарії. `edu-desktop/react` — сам тренажер.

```bash
npm install github:zavada123/edu-desktop#<коміт>
```

Під час встановлення npm сам збирає пакет (скрипт `prepare`). Указуйте конкретний коміт, щоб оновлення тренажера не змінювали перевірку вже виданих завдань.

```tsx
import { EduDesktop } from "edu-desktop/react"
import "edu-desktop/style.css"

// Самоперевірка: учень натискає «Перевірити» в самому тренажері.
<EduDesktop key={scenario.id} scenario={scenario} onCheck={(solved) => console.log(solved)} />

// Перевірка на сервері: сторінка зберігає журнал дій і надсилає його як відповідь.
<EduDesktop key={scenario.id} scenario={scenario} selfCheck={false} initialOps={savedOps} onChange={setOps} />
```

| Властивість | Що робить |
|---|---|
| `scenario` | Завдання. Щоб показати інше, змініть `key` |
| `onCheck(solved)` | Викликається після кожного натискання «Перевірити» |
| `onChange(ops)` | Журнал усіх змін файлової системи після кожної зміни |
| `initialOps` | Журнал, збережений раніше: учень продовжує з того місця |
| `selfCheck` | `false` ховає кнопку «Перевірити», коли перевіряє сайт |

### Перевірка на сервері

Тренажер записує кожну вдалу зміну (`Op`): створити, перейменувати, перемістити, скопіювати, видалити, відновити, створити ярлик, стиснути, видобути, зберегти, відкрити. Номери об'єктів стабільні, тому той самий журнал на тому самому сценарії завжди дає те саме дерево. Сервер не довіряє браузеру: він сам будує початкове дерево, повторює журнал і перевіряє умови.

```ts
import { grade } from "edu-desktop/core"

const result = grade(scenario, ops)
if (!result.ok) {
  // Журнал підроблено або пошкоджено: дія з номером result.index неможлива.
} else {
  result.solved   // усі умови виконано
  result.results  // кожна умова: ok, текст і підказка
}
```

Журнал обмежено: не більше 1000 дій, 1000 об'єктів одночасно і 5000 створених за весь час. Справжнє завдання займає 10–60 дій.
